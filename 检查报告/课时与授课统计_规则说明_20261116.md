# 课时与授课统计规则说明

确认日期：2026-11-16。本轮为说明同步，未修改页面统计、筛选和课时计算逻辑。以下业务口径已确认，实现差异另列。

## 统一规则

- 1课时 = 45分钟，90分钟课程消耗2课时。
- 课时暂不可跨课程通用，按当前学员、所选课程独立核算。语文剩余10课时、数学剩余0课时，仍不能预约消耗数学课时的课程。
- 体验课使用独立课包，不与正式课混用。不能仅凭相同科目将不同课程余额合并抵扣。
- 待确认不冻结课时，最终确认后冻结实际课时，取消或拒绝待确认预约不扣课时。最终确认时须复核所选课程余额与双方时间冲突，防止多份待确认预约同时超额生效。
- 签到成功即代表已完成授课并扣课，立即计入对应课程的已上课时与老师累计授课，不必等待反馈或评价。
- 签到后的待反馈、待评价以及列表里的已完成属于后续处理进度，不等于授课完成统计的触发时点。
- 两个中心的统计不随下方日历月份自动切换。

## 学习中心

按当前学员、所选课程切换统计，四项单位均为课时。四格对应明细须保留同一学员和课程范围。

| 指标 | 已确认口径 |
| --- | --- |
| 已购课时 | 当前学员该课程的已购课时 |
| 已上课时 | 当前学员该课程签到成功、已扣减的课时，包含待反馈、待评价及已完成课次 |
| 已约课时 | 当前学员该课程已最终确认、尚未签到的冻结课时 |
| 剩余课时 | 该课程已购 − 已上 − 已约 |

例：数学已购20、已上4、已约6，剩余10课时。一节90分钟数学课最终确认后，已约变8、剩余变8；该课签到成功后，已上变6、已约回到6、剩余仍为8。语文及体验课余额不受影响。重复签到回调不得重复扣课或累计。

## 授课中心

按当前老师汇总所有课程，预约总单拆分后不重复统计。

| 指标 | 已确认口径 | 单位 |
| --- | --- | --- |
| 累计授课 | 历史授课基数 + 签到成功、已扣减的授课课时，不等待反馈或评价 | 课时 |
| 待我确认 | 仅需当前老师确认的预约，包含待老师处理的指定预约，排除已接单后等待家长确认的记录 | 条 |
| 待上课 | 最终确认后、尚未签到的具体课次 | 次 |
| 待反馈 | 签到成功、尚未提交反馈的具体课次 | 次 |

待我确认数字及红点使用同一范围，点击进入仅需老师处理的列表。等待家长确认的记录仍可在授课记录的待确认标签查看。

例：一份包含20次课的指定预约，待我确认计1条；老师确认生效后，待我确认减少1条、待上课增加20次。某节90分钟课签到后，待上课减少1次、累计授课增加2课时、待反馈增加1次。提交反馈后待反馈减少1次，不再次增加累计授课。

## 当前原型与规则的差异

- 学习中心四格仍读取共享演示汇总，已购96为固定演示值；尚无课程切换、真实订单台账和按学员、课程隔离的统计。体验课记录仍可能混入共享汇总。
- 约课仍读取共享演示余额，按课程校验、冻结、扣减及体验课账本隔离待实现。
- 授课中心仍显示待确认，统计所有已关联老师的待确认记录，包含等待家长确认；待我确认名称、筛选、红点及点击后列表范围待实现。
- 学习中心四格目前都进入上课记录默认列表，按对应指标并保留当前课程范围的明细联动待实现。
- 本轮只同步规则说明，不代表上述页面能力、服务端复核、幂等扣课或实际通知已经实现。

## 后续验收重点

按课程切换、跨课程不可抵扣、不同学员隔离、体验课独立、余额公式、确认冻结、签到转已上、重复回调不重复扣课、反馈不重复累计、待我确认排除待家长记录、预约总单与具体课次不重复计数、数字与红点及明细范围一致。
