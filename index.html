优坐标产品功能当前原型 · 家长端 + 教师端
家长端（7 个模块）
  • 学习中心
    • 学员资料（学员 / 年级）
    • 课时统计：已购 / 已上 / 已约 / 剩余（点击数字进入上课记录）
    • 课程计划查看
    • 入口：去约课 / 上课记录
  • 约课
    • 第 1 步：确认学员与课程
    • 第 2 步：设置固定上课计划（开始 / 结束日期 + 每周上课时段）
    • 第 3 步：选择老师 或 发布需求
    • 指定教师：老师确认即生效
    • 发布需求：多个老师抢单
    • 提交约课 + 确认弹窗，提交后拆分为单节课程
  • 上课记录
    • 标签：全部 / 待确认 / 待上课 / 待评价 / 已完成 / 已取消
    • 筛选：月份 / 课程 / 上课方式
    • 操作：取消约课 / 查看详情 / 重新约课
    • 待上课可请假：填写原因 + 调整上课时间（选新时段）/ 直接取消本次排课
    • 请假需另一方一次响应：按新时间确认 / 直接取消；取消后由平台归还冻结课时
    • 距开课不足 2 小时不可发起；对方响应前可撤回
    • 已完成跳转去评价
  • 课程详情
    • 课程与老师信息
    • 订单状态与课时扣减
    • 查看老师课后反馈 / 去评价
  • 课程评价
    • 老师评分 1~5 星（不再对课程评分）
    • 文字评价
    • 提交后写回订单（已评价）
  • 需求单确认
    • 查看接单老师信息
    • 家长确认 / 拒绝
    • 双方确认后生效并拆单
  • 订单与购课
    • 购买课程 / 订单确认
    • 我的订单：全部 / 待支付 / 已支付 / 已取消
    • 订单详情：支付 / 再次购买 / 立即约课
教师端（7 个模块）
  • 授课中心
    • 教员资料 / 资料管理
    • 累计授课 / 待确认 / 待上课 / 待反馈
    • 本月排课与日历视图
    • 入口：可约时段 / 抢单大厅 / 授课记录
  • 可约时段
    • 四类时间：工作日白天 / 工作日晚上 / 周末白天 / 周末晚上
    • 特殊日期：全天开放 / 当天不开放 / 跟随四类时间（删除即恢复跟随）
    • 保存后进入家长可约范围
  • 抢单大厅
    • 待接单需求列表 + 刷新
    • 接单操作、等待家长确认状态
    • 新单红点提示
  • 授课记录
    • 标签：待确认 / 待上课 / 待反馈 / 已完成
    • 拒绝约课 / 确认约课
    • 待上课可请假 / 响应（与家长端对等）：调整时间需对方确认，取消确认后由平台归还课时
    • 模拟签到回调
    • 已完成课程展示反馈与作业；分享文案在课程详情页
  • 课程反馈
    • 课程内容 / 课后反馈 / 作业要求
    • 提交后订单进入已完成
  • 课程详情
    • 学员与课程信息
    • 去填写反馈 / 分享文案至家长群
  • 消息与提醒
    • 新增需求红点
    • 个人中心入口提醒

业务流程图 · 泳道串联

横向为责任方泳道（教师端 / 家长端 / 平台），纵向为时间顺序：教师维护可约时段 → 家长购课并制定上课计划 → 确定老师 → 拆分为单节课程 → 待上课可请假 → 一次响应后判断（改期生效 / 取消由平台归还课时）→ 签到扣课时 → 课后反馈 → 家长评价收尾。整条主线自上而下依次串联，仅在「A 指定老师 / B 发布需求」处分支一次，随后立即汇合。待上课阶段家长与老师任一方均可请假：填写原因后选择调整上课时间（须选新时段）或直接取消本次排课，另一方一次响应——按新时间确认则改期继续，直接取消则归还冻结课时。

请假说明：待上课阶段任一方可发起请假（填写原因 + 调整上课时间 / 直接取消本次排课），另一方只能「按新时间确认」或「直接取消课程」，一次响应即终态；距开课不足 2 小时不可发起，对方响应前可撤回。

分支说明：A 指定老师——教师拒绝或超时未确认时，家长可重新选择老师，或改为发布需求；B 发布需求——在家长确认接单老师前，需求在抢单大厅保持可抢状态（接单后家长取消则不再进入后续流程）。两条路径汇合于「预约生效 · 拆分单节课程」。
